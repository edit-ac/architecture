# General retained-source ownership v3

Status: locally qualified disposable representation for ENG-1.17; see [the matching receipt](../evidence/engine-ownership-profile/receipt.json). Production integration remains ENG-1.18. This is no performance, persistence, deployment or publication claim.

## Envelope and exact roots

Schema `editac.registry.structure.v3`, profile `editac.yrs-yjs.structure.v3`; protocol 1, encoding 1, UTF-16, Yrs 0.28.0 small-client, Yjs 13.6.33. Exact immutable protocol-v1 envelope with distinct document/epoch, externally stored initialized flag and fresh live writer IDs. No automatic migration, mutation of v1/v2, or reseeding restore.

Seven root Y.Map / MapRef types: `registry-parents` maps original ID to immutable `block`; `registry-texts` maps original ID to persistent nested Y.XmlText / XmlTextRef; `registry-placements` maps original ID to atomic `["@root", integral order]`; `delete-probe-tombstones` maps original/derived owner ID to true; `registry-block-attributes` uses the v2 immutable JSON-array tuples; `registry-ownership-ops` maps unique operation ID to immutable atomic array; `registry-owner-origins` maps original ID to true (explicit original-owner membership). No `probe-split-join` root in this profile. This qualification has ordinary block kinds only; future structural kind extensions require their own contract/qualification.

Original IDs are `n:<writer>:<counter>`, operation IDs `o:<writer>:<counter>`, with decimal positive integers without leading zero, writer <= 4294967295, counter <= 4294967295. Allocate counters monotonically in persisted writer sessions, never reuse live writer identity. Original and operation namespaces are separate. A split's new owner is its operation ID; no text/kind/placement is created for it.

## Atomic operations and deterministic replay

`["split", leftOwner, leftVersion, spanIndex, sourceId, binaryRelativeCut]` or `["join", leftOwner, leftVersion, rightOwner, rightVersion]`. Initial versions are `"base"`; a successful operation sets all surviving affected owner versions to its own ID. Split left survives; new right has that version. Join left survives, right is absorbed. Cuts use encoded Yjs relative position / Yrs StickyIndex, affinity Before (-1), attached to the named original text. spanIndex identifies an exact span in a multi-source owner, including empty spans. A split partitions that span at its current resolved cut, retains both empty sides, and distributes preceding/following spans. Join concatenates the adjacent visible owners' spans. No text writes, cloning or delete/reinsert implement structure.

Dependencies are all non-base version tokens. Validate the complete graph without recursion; reject cycles. Missing dependency records are retained dormant, not applied or repaired. Rank known records topologically: depth (base depth 1), then numeric writer, then numeric counter. Process that total order once. An operation applies only when all dependencies succeeded, its target versions match, targets exist, are not tombstoned, and joins are adjacent. Otherwise retain its ID and tuple as a losing/recoverable intention; descendants remain losing/dormant. Independent pairs commute. Concurrent overlapping intentions choose the first eligible operation in the documented order, never arrival order or a merge of tuple fields. A newly arrived earlier-ranked intention can change the read projection; the operation log and original content are retained.

A missing-source or unresolved cut (including absent binary dependency) is dormant/recoverable. A resolved cut in a different text, wrong affinity, surrogate interior or outside its identified span is invalid and rejects admission. Text deletion collapses relative boundaries; empty spans survive. Concurrent insertion exactly at a Before cut belongs to the right span; inserts before/after it route by the relative boundary. Structural content uses existing marks on the original shared text; projection slices attributed runs in UTF-16 and never writes repairs.

## Presentation, anchors, deletion and recovery

Initial owner order is `(placement order, numeric original ID)`; successful split inserts immediately after left; join requires adjacency. Original tuple default is paragraph. A derived owner uses its explicit tuple or recursively the live tuple of the split's left owner; inheritance terminates at an original. Join preserves left tuple, retains absorbed right tuple. Dormant/losing derived overrides remain retained. Unknown JSON tuple discriminants and original character marks stay opaque; no extension execution/fetch. Local formatting of unknown or nonvisible owners is unsupported.

Tombstones monotonically hide owner IDs. They do not delete texts or metadata. Replay refuses an operation targeting a tombstoned owner. A tombstoned derived owner still exists if its successful producing split exists; its spans are recovery content. A deleted original prevents its lineage operations, retaining the original source as recovery. Projection emits ordered visible owners and deleted owners with spans, plus original texts/tuples, complete retained operation intentions (binary cuts represented as byte arrays in JSON), and operation outcomes for recovery. Unknown tuples retain their raw value alongside an explicit paragraph presentation fallback. Absorbed owner metadata and losing intentions are retained, but do not duplicate character ownership. Every retained source UTF-16 character belongs exactly once to a visible or deleted/recoverable span; empty spans own no characters.

Anchors remain binary positions in the original text. Resolve first to original source/offset, then to current visible/recovery span owner. Interior points have one owner. At shared boundaries Before chooses the earliest span ending there; After chooses the latest span starting there, with deterministic owner/span order for empty ties. Return deleted for tombstoned ownership, unresolvable for missing identities, never silently redirect. Marks and structural changes preserve original integrated branch IDs.

## Admission and resource envelope

Check exact external envelope/initialized state before decoding. Reject >16 MiB update/checkpoint; stage on a disposable replica, validate exact root names and types, all atomic tuples/text types/IDs/placements/metadata/tombstones and operation graph, then apply once under explicit origin. Compare existing immutable original kinds/origins and operation values; replacement/removal is invalid. Missing Yrs binary dependencies require explicit recovery rather than live mutation. Retain rejected user-owned bytes/envelope externally; no unbounded attacker storage. No profile fallback or migration.

Bound projection/admission to 4096 original sources, 4096 operations, 8192 owner spans, 1 MiB UTF-8 source text total, 262144 UTF-16 units per source, graph depth 128, JSON tuple depth 32, 96-byte IDs and 256-byte cuts. Decode additionally caps nested binary Any depth at 32, each container at 8192 entries, total Any values and structs at 262144, and unsigned u32/usize allocation/clock fields at 2097152 before allocation; larger clocks are outside this probe envelope. Graph ranking is iterative O(operations squared), capped at 16777216 dependency visits; span coverage checking is bounded by these limits. Command preparation must consume these same limits and validate current versions/anchors before one explicit-origin commit (ENG-1.18). This is a functional resource ceiling, not a latency/performance claim. Exhaustion produces typed resource-limit/recovery, never partial state or silent omission.

## Alternatives

Copying rich text on each split loses integrated identity and concurrent edit routing. One global replacement descriptor gives atomic conflicts but cannot merge disjoint pairs or retain repeated branches. Independently merged per-owner span fields can overlap or orphan content. The selected operation log preserves source identity, serializes only overlapping intentions deterministically and retains losing intentions; it trades bounded replay/history cost for explicit recovery. Rejected alternatives are design comparisons, not falsely reported executed probes.
