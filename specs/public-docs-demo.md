## Editor migration guides

Add a dedicated `content/docs/migrate/` section with an overview, one guide per source editor, and shared HTML/Markdown/plain-text routes. Cover Tiptap, ProseMirror, Lexical, Slate/Plate, Quill, Draft.js, Editor.js, BlockNote, CKEditor 4, CKEditor 5 and TinyMCE. Shared routes include entry points for Froala, Summernote, CodeMirror and Monaco; do not assume those products store the same semantic model. Prioritize Tiptap, ProseMirror, Lexical, Quill and HTML, while keeping each guide independently deliverable. Link migration and comparison sections from the docs landing page, import/export, getting started and compatibility pages; register canonical pages in `navigation.json`.

Every guide records exact source versions, schema/plugins, target SDK/converter profile and planned/experimental/qualified maturity. Show native source export, feature mapping, input fixture, expected target semantic snapshot, rendered result and conversion diagnostics. Cover formatting, nested lists, links, code, tables, images, Unicode and an unsupported/custom-content example. Source exporters may run against pinned dependencies before a target converter exists; target API snippets remain explicitly conceptual until an immutable packaged consumer and direction-specific fidelity evidence pass. Direct source JSON is preferred when a qualified adapter preserves more semantics; HTML/Markdown routes declare their losses. Content conversion does not migrate plugins or editor behavior.

Unknown bounded source data must be preserved with source locations and recovery diagnostics rather than silently discarded. Show preview/review before commit, cancellation, failures and rollback. Include assets, document-ID mappings, application permissions/metadata, comments/suggestions/history scope, resumable/idempotent batch migration and validation. Collaborative cutover captures an authoritative snapshot and handles outstanding/offline writers under a declared host policy, then starts a new explicit target epoch/session. Tiptap/ProseMirror Yjs bytes do not establish edit.ac schema compatibility; retain the original data and explain how rollback avoids losing post-cutover edits.

The shared fixture contract uses redistributable deterministic source documents and independently authored expected semantics/diagnostics, not converter-generated expected values. Tiptap and Quill fixtures for the same bold paragraph must agree semantically without treating their JSON structures as interchangeable. Tests cover unsupported content, malformed input, resource limits, assets and interrupted/repeated conversion. A planned guide can pass documentation/source-export checks while target conversion remains unqualified; do not count missing converter execution as a passed conversion test.

No overall winner or unqualified binary checkmark substitutes for workload-specific tradeoffs.

Benchmarks consume REL-1.2/1.3/1.4 evidence under [verification](verification.md); docs do not own a duplicate execution harness. Reuse the declared Task/Long/Large/Aged corpus and document small/medium/large labels; stress results do not expand supported limits.

Publish reproducible accessible tables/charts and downloadable sanitized evidence, including regressions and limits; comparison fixtures never invoke paid inference or record live providers.
