## Runtime matrix and evidence

EXT-1.18 runs deterministic mode/configuration/replacement checks and supplies the browser fixture/runbook; INT-1.14 supplies actual browser/OS observations. Cover each claimed Chromium, Firefox and Safari/WebKit profile, desktop/mobile where claimed, with the user's checker on/off and supported locale plus unavailable-locale cases. A standalone Playwright WebKit replay is not a Safari or mobile OS observation. Reuse existing browser qualification hosts and record browser and OS versions separately.

Native -1.6/-1.7 owners run the relevant prepared and actual-control cases for iOS, Android, macOS, Windows and Linux independently. DEL-1.7 consumes exact-artifact observations, including enabled/disabled settings, supported OS spelling suggestions and command/menu/gesture history. Record toolkit/OS, selected keyboard/IME, locale, profile, requested/effective/unknown state, physical/virtual provenance and unsupported service combinations. Virtual platforms and tested hardware-only equivalents follow [verification](../specs/verification.md#platform-qualification-with-simulators-emulators-and-vms); absence of a native platform does not block independent browser implementation.

Use content, formatting, directional selection/pending marks, attributable commits/updates, shared history counts and resource/request counts as oracles. Separate prepared traces from actual OS observations. Missing mandatory coverage, zero matches and skips fail the applicable gate. An unavailable optional facility is accepted only with observed availability diagnostics and a passing no-service fallback, not a pass for that service. Restore isolated profile settings and preserve failures. All custom checker/text-service data is prepared or mocked; no paid/API inference, ambient credentials, recording or live provider validation.
